# 怎麼寫題材包

題材包讓不同的故事有不同的味道：武俠有江湖氣，克蘇魯有說不出的壓迫感。只要會寫 markdown，新增一個資料夾就能加入新的題材，不用改程式。

結構仿照 [Agent Skills](https://code.claude.com/docs/en/skills)（Claude Code 的 skill）：每個題材一個資料夾，裡面一份 `GENRE.md`。

## 放在哪裡

| 位置 | 用途 |
|---|---|
| `src/story/genres/` | 內建的題材，跟著專案一起管理（commit 後大家都有） |
| `~/.config/story/genres/` | 個人的題材，只有你自己的電腦用得到 |

`name` 相同時個人的優先，所以想調整內建題材的風格，可以在個人資料夾放一份 `name` 相同的題材包（資料夾名稱不必相同），不用改動內建的那份。網頁版讀的是架設伺服器那台電腦的資料夾。

## 資料夾內容

```
wuxia/            資料夾用英文名稱（跨平台、跨工具比較不會出問題）
├── GENRE.md      必要：設定欄位＋寫作指引
├── premises.md   選用：開頭靈感（隨機開頭、「換一個」、「幫我想」都會用到）
├── names.md      選用：人名、地名、組織名的素材
└── twists.md     選用：轉折靈感（讓第三幕的轉折更有變化）
```

### `GENRE.md`

```markdown
---
name: 武俠
description: 江湖恩怨、門派紛爭、俠義與復仇。適合比武、追殺、尋找秘笈、護送與報恩的故事。
---

## 文風
……

## 世界與常見元素
……

## 要避免的套路
……
```

- `name`：題材名稱，會顯示在選單裡，例如「武俠」。不寫的話用資料夾名稱。
- `description`：一兩句話說明這是什麼題材、適合什麼故事。**AI 選「自動」時就是靠它判斷**，所以要寫出適合的情境，200 字以內。
- 內文：給 AI 的寫作指引，**每回合都會送出**，2,000 字以內。標題怎麼分可以自由決定，內建的題材用的是「文風、世界與常見元素、常見橋段、節奏、要避免的套路」。

### `premises.md`

一行一個開頭靈感，可以用 `-` 開頭，2,000 字以內。用在兩個地方：

- **隨機開頭**：開新故事時，「留白則使用」的前提是從這裡隨機抽的（選了題材就從那個題材抽，選「自動」就從所有題材包抽），按「換一個」會重抽。所以每一則都要能直接當故事前提用：第二人稱、一兩句話、交代身分與處境，並留下謎團或危機。
- **「幫我想」**：挑到這個題材時，隨機給 AI 其中三則當參考（AI 會寫出新的，不會照抄）。

### `names.md`

人名、外號、地名、組織名的素材，自由格式。規劃大綱與寫開場時給 AI 參考。2,000 字以內。

### `twists.md`

一行一個轉折靈感，可以用 `-` 開頭，2,000 字以內。

故事分成四幕：起、承、轉、合。規劃大綱時，AI 要先想好一個玩家不知道的「隱藏真相」，在第三幕（轉）揭露，並設計前兩幕要埋的伏筆。程式會從這裡隨機抽三則給 AI 參考，請它挑一則改寫成適合這個故事的版本（或想出更好的），所以同一個題材玩很多次，轉折也不會每次一樣。

```markdown
- 當年滅門的元兇不是仇家，而是主角一直敬重的師父；仇家其實是想保護主角的人。
- 人人爭奪的絕世秘笈是假的，真正的武學早就藏在主角從小背熟的口訣裡。
```

好的轉折會**顛覆玩家對處境的理解**，而且事後回想合理：寫「誰其實是誰」「事情其實是為了什麼」，而不是「突然出現更強的敵人」。轉折要落在 NPC、事件、地點或過去的秘密上，**不要寫成「主角其實早就死了」「主角其實被寄生了」**：角色的生死由程式依傷勢判定，多人模式時也不該只讓某一位玩家的角色承擔真相。不用寫得很細，AI 會依故事前提調整人物與細節。沒有這個檔案時，AI 照樣會自己設計轉折，只是比較容易落入老套。

## 每個檔案什麼時候用到

跟 skill 一樣「用到才載入」：

| 內容 | 什麼時候給 AI |
|---|---|
| 名稱＋描述 | 玩家選「自動」時，開局先給 AI 整份目錄，請它依故事前提挑一個（之後才規劃大綱，所以大綱也用得上這個題材的內容） |
| `GENRE.md` 內文 | 選定題材後，整局每回合都放在提示詞前段 |
| `names.md` | 規劃大綱與寫開場 |
| `twists.md` | 規劃大綱（隨機抽三則） |
| `premises.md` | 隨機開頭與「換一個」（直接抽，不經過 AI）；按「幫我想」挑到這個題材時給 AI 參考 |

## 寫得有效的訣竅

- **寫具體的東西，不寫抽象的形容**：「請寫得像武俠小說」幾乎沒有效果，模型本來就大概知道武俠是什麼。有效的是具體的用詞、人物類型、會推動劇情的事物、常見橋段。
- **接上遊戲的機制**：遊戲有身體與精神狀態、背包、限時模式。告訴 AI 這個題材裡什麼會造成什麼狀態，例如克蘇魯「看到越多真相，精神狀態越差」、武俠「中毒、內傷要找名醫」。
- **寫出要避免的套路**：AI 很容易寫出最常見的老梗，明確列出來比較有效。
- **保持精簡**：指引每回合都會送出，太長會稀釋其他規則。內建的題材大約 500 字。

## 怎麼確認有沒有寫錯

格式不對的題材包會被略過，不會讓遊戲出錯。在專案資料夾執行下面的指令，可以看到讀到哪些題材，以及被略過的題材和原因：

```bash
uv run python -c "from story.core.genres import load_genres; g, p = load_genres(); print(list(g)); print(*p, sep='\n')"
```
